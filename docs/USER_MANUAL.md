# Chapter 1: はじめに

## 1.1 LiveLingoとは

**「言語の壁を超えて、世界中の人々がリアルタイムで繋がる」**

LiveLingoは、最短1秒の遅延でプロの同時通訳者と同等以上の速度を実現する国産AIリアルタイム翻訳アプリです。

### 主な特徴

| 特徴 | 説明 |
|------|------|
| **超低遅延** | 最短1秒、長文でも3秒以内の翻訳遅延 |
| **高精度** | カスタマイズLLMによる文脈を考慮した翻訳 |
| **自然な音声** | 10,000種類以上のAI音声モデル |
| **多言語対応** | 8言語間の双方向音声通訳 |

---

## 1.2 主な機能と特徴

### コア機能

#### リアルタイム音声認識（STT）
- 発話をリアルタイムでテキスト化
- 認識精度95%以上（標準環境）
- 「間」検出による意味区切りの自動判定
- ノイズキャンセリング前処理

#### リアルタイム翻訳
- 認識テキストを即座に翻訳（500ms以内）
- 会話履歴を考慮した文脈保持翻訳
- 専門用語辞書のカスタム登録対応
- BLEU スコア40以上の高品質翻訳

#### 音声合成出力（TTS）
- 翻訳結果を自然な音声で再生（200ms以内）
- CoeFont AI音声による10,000+音声モデル
- 音声速度・ピッチの調整可能
- Personal Voice（ユーザー声クローン）対応

#### 双方向通訳
- 2人の異なる言語話者を同時認識
- 話者の自動識別
- 各話者に最適化された音声出力

### 拡張機能

| 機能 | 説明 | 優先度 |
|------|------|--------|
| カスタム音声作成 | ユーザー自身の声で音声合成 | P1 |
| 会話履歴保存 | 翻訳履歴の保存・検索 | P1 |
| 専門用語辞書 | カスタム辞書登録機能 | P1 |
| オフラインモード | 一部言語のオフライン対応 | P1 |
| Apple Watch連携 | Apple Watchからの操作 | P2 |
| ウィジェット対応 | ホーム画面ウィジェット | P2 |

# Chapter 2: クイックスタート

## 2.1 インストール方法

### App Storeからインストール

1. **App Store** を開く
2. 検索で「**LiveLingo**」を入力
3. **入手** ボタンをタップ
4. Face ID / Touch ID で認証
5. インストール完了を待つ

### 開発者向け（ソースからビルド）

```bash
# リポジトリをクローン
git clone https://github.com/ryoma3736/LiveLingo.git
cd LiveLingo

# XcodeGenでプロジェクト生成
brew install xcodegen
xcodegen generate

# Xcodeで開く
open LiveLingo.xcodeproj
```

---

## 2.2 初回セットアップ

### Step 1: 権限の許可

アプリ起動時に以下の権限を要求されます：

| 権限 | 用途 | 必須 |
|------|------|:----:|
| **マイク** | 音声入力・認識 | Yes |
| **音声認識** | Apple Speech Framework | Yes |
| **通知** | 翻訳完了・エラー通知 | No |

> **重要**: マイク権限を拒否すると、アプリのコア機能が使用できません。

### Step 2: 言語選択

1. 翻訳元言語（あなたが話す言語）を選択
2. 翻訳先言語（相手の言語）を選択
3. 言語パックのダウンロード（必要に応じて）

### Step 3: 音声テスト

1. **テスト開始** ボタンをタップ
2. 「こんにちは」と話しかける
3. 翻訳結果が正しく表示されることを確認

---

## 2.3 APIキー設定

### Gemini API Keyの取得

LiveLingoは高精度翻訳に Google Gemini API を使用します。

1. [Google AI Studio](https://ai.google.dev/) にアクセス
2. Googleアカウントでログイン
3. 「**Get API key in Google AI Studio**」をクリック
4. 「**Create API Key**」を選択
5. 表示されたキーをコピー

### アプリへの設定

**方法A: アプリ内設定**

1. **設定** 画面を開く
2. **API設定** → **Gemini API Key**
3. コピーしたキーを貼り付け
4. **保存** をタップ

**方法B: 環境変数**

```bash
export GEMINI_API_KEY="your-api-key-here"
```

# Chapter 4: コア機能詳細

## 4.1 音声認識（STT）

### 処理フロー

```
マイク入力
    ↓
オーディオバッファ（PCM 16kHz, モノラル）
    ↓
ノイズキャンセリング前処理
    ↓
Apple SFSpeechRecognizer
    ↓
「間」検出（ポーズ検出）
    ↓
部分結果出力（50ms間隔）
    ↓
確定結果出力
```

### 認識パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| サンプルレート | 16kHz | 音声品質 |
| バッファサイズ | 512 samples | レイテンシ |
| 短い間閾値 | 0.3秒 | 文中の区切り |
| 長い間閾値 | 0.8秒 | 文末の区切り |
| 無音判定 | -40dB | 無音検出 |

### 認識精度向上のコツ

1. **静かな環境**: 背景ノイズを最小限に
2. **適切な距離**: マイクから15-30cm
3. **明瞭な発音**: ゆっくり、はっきりと
4. **外部マイク**: AirPods推奨

---

## 4.2 翻訳エンジン

### 翻訳戦略：Wait-k Attention

LiveLingoは「Wait-k Attention」戦略を採用し、リアルタイム翻訳を実現します。

```
話者: 「今日は」「天気が」「いいですね」
         ↓       ↓        ↓
翻訳:   待機   「Today」  「is nice weather」
```

- 意味の区切りを検出して翻訳開始
- 文脈を考慮した高品質翻訳
- 部分結果も随時表示

### 翻訳エンジン切替

| モード | 特徴 | 使用場面 |
|--------|------|----------|
| **オンデバイス** | 低遅延、オフライン可 | 簡単な会話 |
| **クラウド（Gemini）** | 高精度、文脈考慮 | ビジネス、専門 |
| **ハイブリッド** | 自動切替 | 通常使用 |

### 専門用語辞書

カスタム辞書を登録することで、専門用語の翻訳精度を向上できます：

1. **設定** → **辞書管理**
2. **新規追加** をタップ
3. 原語と訳語を入力
4. **保存**

# Chapter 5: 高度な設定

## 5.1 音声設定

### オーディオセッション

LiveLingoは同時入出力セッションを使用し、録音と再生を同時に行います。

**推奨設定:**

| 設定項目 | 推奨値 |
|----------|--------|
| カテゴリ | Play and Record |
| モード | Voice Chat |
| サンプルレート | 16kHz |
| IOバッファ | 5ms |

### 入出力デバイス

**入力デバイス優先順位:**
1. 外部マイク（接続時）
2. AirPods / Bluetooth
3. 内蔵マイク

**出力デバイス優先順位:**
1. AirPods / Bluetooth
2. 外部スピーカー
3. 内蔵スピーカー

### ノイズキャンセリング

| レベル | 効果 | 処理負荷 |
|--------|------|----------|
| OFF | なし | 低 |
| 低 | 軽度のノイズ除去 | 中 |
| 高 | 強力なノイズ除去 | 高 |

### 翻訳モード

| モード | 遅延 | 精度 | データ |

| **高速** | ~0.5秒 | 中 | 少 |
| **バランス** | ~1秒 | 高 | 中 |
| **高精度** | ~2秒 | 最高 | 多 |

### 文脈保持設定

| 設定 | 説明 |

# Chapter 6: トラブルシューティング

## 6.1 よくある問題と解決策

### 音声が認識されない

| チェック項目 | 解決策 |
|-------------|--------|
| マイク権限 | 設定 → プライバシー → マイク → LiveLingo ON |
| マイク距離 | 15-30cmの距離で話す |
| 背景ノイズ | 静かな環境で使用 |
| 言語設定 | 正しい言語が選択されているか確認 |

### 翻訳結果が表示されない

| チェック項目 | 解決策 |
|-------------|--------|
| ネットワーク | インターネット接続を確認 |
| APIキー | 設定 → API設定 でキーを確認 |
| 言語パック | 必要な言語パックをダウンロード |

### 音声が再生されない

| チェック項目 | 解決策 |
|-------------|--------|
| 音量 | デバイスの音量を確認 |
| サイレントモード | 解除する |
| Bluetooth接続 | 出力デバイスを確認 |
| TTS設定 | 音声タイプを変更してみる |

### アプリがクラッシュする

```bash
# キャッシュクリア手順
1. アプリを完全終了
2. 設定 → LiveLingo → データを削除
3. アプリを再起動
```

## 6.3 FAQ

### 一般的な質問

**Q: オフラインで使用できますか？**

A: 一部の言語（英語、日本語、中国語、韓国語）はオフラインで使用可能です。ただし、高精度翻訳にはインターネット接続が必要です。

**Q: 会話は録音されますか？**

A: デフォルトでは会話データはデバイス内にのみ保存されます。クラウドへのアップロードは行いません。プライバシーモードを有効にすると、一切のデータ保存を無効にできます。

**Q: バッテリー消費が激しいのですが？**

A: 低電力モード設定を有効にするか、翻訳品質を「高速」に変更してください。また、画面輝度の調整も効果的です。

### 技術的な質問

**Q: 対応しているBluetoothコーデックは？**

A: AAC、SBC、aptXに対応しています。最高品質にはAACを推奨します。

**Q: APIキーを複数デバイスで共有できますか？**

A: はい、同じAPIキーを複数のデバイスで使用できます。ただし、レート制限は共有されます。

**Q: 専門用語辞書の登録上限は？**

A: 無料版は100語まで、プレミアム版は無制限です。
