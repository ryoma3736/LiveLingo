# LiveLingo - コアパイプライン単体テスト設計書

## 概要

本ドキュメントは、LiveLingoのコアパイプライン（音声入力→認識→翻訳→音声出力）に関する単体テスト設計書です。

**対象データフロー**: DF-CORE-001 〜 DF-CORE-012 (12 flows)
**テストケース総数**: 85+ cases

---
